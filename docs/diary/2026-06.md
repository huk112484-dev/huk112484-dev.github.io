### 用自己的话讲一遍

我意识到，学习日记不是简单记录每天做了什么，而是把学习过程沉淀成可以长期复盘、持续展示的成长轨迹。

它是什么 → 为什么用 → 怎么操作 → 遇到什么坑 → 下次怎么复用。

VitePress 就像一个“把 Markdown 变成网页的工具”。我写 `.md` 文件，相当于写文章；GitHub 负责保存这些文件；GitHub Pages 负责把它们变成别人能访问的网站。

所以整个流程是写 Markdown → 提交 Git → 推送 GitHub → 网站自动更新
