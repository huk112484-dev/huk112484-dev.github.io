# 无人机无线电地图与路径规划

## 1. 项目定位

本项目关注城市低空无人机起降阶段的通信感知轨迹规划问题。

传统无人机路径规划通常关注路径长度、避障和可达性，但在城市三维空间中，建筑遮挡、多径传播、基站覆盖不均和临时干扰会形成局部弱信号区域。因此，几何最短路径并不一定是通信可靠的路径。

本项目的核心目标是：利用三维无线电地图刻画空间中的通信质量分布，在无人机起降过程中同时考虑可达性、避障约束和通信可靠性，并在通信环境变化时实现动态重规划。

## 2. 研究场景

当前场景面向城市低空无人机降落任务。无人机从高空位置逐步下降到目标 landing zone，需要在避开建筑物的同时，尽量降低弱信号暴露比例。

该场景包含两个层次：

1. **静态规划**：起飞前已知三维无线电地图，离线规划一条通信质量较好的路径；
2. **动态执行**：飞行过程中局部通信环境发生变化，需要在线调整路径或触发安全接管。

## 3. 核心问题

本项目主要回答三个问题：

1. **通信感知规划的必要性**  
   在无人机起降路径规划中，引入三维无线电地图后，是否能够显著降低弱信号暴露，并提升路径通信可靠性？

2. **动态通信扰动下的重规划能力**  
   当飞行过程中出现局部弱信号空洞、遮挡变化或通信质量突变时，学习型重规划方法是否能够比传统图搜索重规划更有效地调整路径？

3. **面向实际执行的可靠性保障**  
   当学习策略出现不安全动作、进入弱信号区域或偏离安全路径时，如何通过安全监督与 fallback 机制保证无人机最终可靠降落？

## 4. 方法路线

当前方法由三层组成：通信感知 A* 基线、A*-guided constrained PPO 和 safety supervisor。

### 4.1 通信感知 A* 基线

A* 在本项目中不是主创新，而是作为可解释 baseline、专家规划器和安全兜底模块使用。

主要包括：

- **shortest A***：只优化几何距离；
- **radio-aware A***：在路径代价中加入通信质量因素；
- **strong radio-aware A***：更强地规避弱信号区域；
- **strict reliability A***：尽量完全避开弱信号区域。

### 4.2 A*-guided constrained PPO

PPO 是当前主方法，用于学习动态通信风险下的重规划策略。

主要设计包括：

- **A* guidance**：提供全局路径方向和专家先验；
- **demonstration pretraining**：利用 A* 示范轨迹降低探索难度；
- **action mask**：屏蔽明显非法动作；
- **weak-signal constraint**：约束弱信号暴露；
- **safety fallback**：策略不安全时由通信感知 A* 接管。

### 4.3 Safety supervisor

真实无人机不能接受中途失败，因此加入安全监督层。当策略出现碰撞风险、连续弱信号、偏离安全参考路径或无法到达 landing zone 时，系统触发 fallback 机制，优先保证最终可达。

## 5. 当前关键结论

目前实验说明：

1. **通信感知路径规划是必要的**。普通 shortest A* 虽然路径短，但弱信号暴露高；radio-aware / strong A* 能显著降低 weak ratio。
2. **静态已知地图中 strong A* 是很强的基线**。PPO 也没有在静态全面超过 A*。
3. **PPO 的主要价值体现在动态通信扰动下**。动态实验中，PPO dynamic replanning 的 weak ratio 明显低于传统 replanned strong A*。
4. **A* guidance 和 demonstration pretraining 是 PPO 稳定学习的关键**。A* 在本文中应定位为专家先验和安全支撑。
